The game catalog includes Bethesda games. Added games can use compatible Unity Mono, Unity IL2CPP, or Unreal workflows.

An engine match alone does not guarantee support. Mods can require a specific loader, game version, storefront, or operating system.

## Catalog games

1. Open **Games**.
2. Find the correct game and edition.
3. Use that game when you [create a profile](../first-profile/).
4. Check the installation source and game folder.

Do not select a different edition to bypass a setup problem. Plugins and components can depend on the exact edition.

## Add a game

1. Open **Games**.
2. Select **Add game**.
3. Select the installation source.
4. Select the Steam installation or supply the game folder.
5. Check the detected engine and game details.
6. Complete the required fields.
7. Select **Add game**.

The setup also offers **Add game** during profile creation. An added game becomes a choice for profile setup.

Use **Advanced** only when you know the correct game details. Manual registration does not make every game compatible.

## Unity games

Unity Mono and Unity IL2CPP use different loader builds. A loader for one type is not interchangeable with the other.

1. Check the detected Unity type.
2. Read the mod's game and loader requirements.
3. Open the game's **Mod loader** controls.
4. Check the displayed BepInEx package and version.
5. Enable the loader choice.
6. If no package is available, install a compatible loader archive through **Archives** first.
7. Check the result before you add dependent mods.

Do not substitute a random BepInEx archive when a compatible package is unavailable. Check the game community's instructions first.

## Unreal games

Unreal games can use supported package or loader workflows. The required files and loader depend on the game and mod.

1. Read the mod's supported game versions and installation requirements.
2. Check **Mod loader** for the selected game.
3. Supply the required compatible files when prompted.
4. Test a small profile before you add more mods.

Do not assume that all Unreal games accept the same loader or file layout.

## Mod sources

Nexus Mods and Thunderstore availability depends on the selected game. A local archive remains a separate installation route.

Use the Thunderstore community for the correct game. A matching package name in another community does not prove compatibility.
