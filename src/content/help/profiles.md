A workspace can contain several profiles. Profiles can share installed mods while each profile keeps its own enabled choices, order, and private files.

## Select a profile

1. Open the workspace's profile cards or profile selector.
2. Select the required card and **Use profile**, or select it in the profile selector.
3. Check its game installation and setup status.
4. Check its enabled mods and order.
5. Select **Play** when the profile is ready.

Profile selection does not prove that deployment or Linux runtime setup is complete. Resolve a displayed problem before launch.

## Settings and private files

1. Open **Settings and saves** for the selected profile.
2. Select **Edit settings** for the available profile options.
3. Check any proposed game-configuration change.
4. Apply only the intended change.

Use **Edit profile files** to inspect the private files for the profile. Do not edit a different profile's files by path guesswork.

A private save location is separate from the game's global save location. Support depends on the game's known local save paths.

## Save files

1. Open **Settings and saves** for the profile.
2. Select **View save files**.
3. Select **Profile** to inspect private saves.
4. Select **Global** to inspect the qualified local game saves.
5. Select the required save groups.
6. For global saves, select **Copy to profile**.
7. Read the preview and confirm only the intended files.

A save group can include a companion file. Keep the files together when the preview identifies them as one group.

**Delete** in the Profile view removes selected private saves. Back up important saves before you confirm deletion.

Steam Cloud is not managed here. These controls do not change Steam Cloud data or guarantee cloud synchronization.

## Export a profile

1. Open **Options for** the required profile card.
2. Select **Export profile**.
3. Read the profile summary.
4. Enter a **File name** that ends with `.mcprof`.
5. Select **Include save games** only if you want to share those saves.
6. Select **Export profile** and choose a destination.

A `.mcprof` file records the profile for import. It is not a universal game installation or a backup of all mod archives.

Check the file before you share it. Included saves and profile files can contain personal data.

## Import a profile

1. Select **Import profile** and choose a `.mcprof` file, or open the file with Mod Conductor.
2. Read the import summary.
3. Select a suitable **Workspace** or select **Create new workspace**.
4. Select a ready **Game installation**, or complete setup in the new workspace.
5. Supply the exact missing local archives requested by the import.
6. Complete any required Nexus download action.
7. Select **Import profile**.
8. Check the imported profile's mods, order, runtime, and private files before Play.

Import needs the exact archives for the referenced mods. Available Nexus files can download after confirmation, subject to account limits.

Do not replace a missing archive with an unrelated version. Resolve the missing source before you continue.

## Delete a profile or workspace

To delete a profile, first select another profile. Read the deletion warning before you confirm.

Profile deletion permanently removes that profile's private settings and saves. Installed mods and other profiles remain unchanged.

Workspace deletion has a wider scope. Back up the workspace and read the affected-file preview before you confirm its deletion.
